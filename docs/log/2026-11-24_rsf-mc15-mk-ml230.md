# 2026-11-24 — The RSF MC 15 MK scale with a 230 mm measuring length is in the library

**Role(s):** mechanical engineering, purchasing

## What changed

The library now has a third length of the RSF MC 15 MK steel tape scale: MB-MC15-MK-ML230, with a
230 mm measuring length on a tape 250 mm long. The 220 mm and 240 mm scales stay in the library,
unchanged.

The 230 mm scale is our own model. It is the 240 mm model with only the measuring length changed,
built from the same RSF drawing.

## Why it matters

The aqtuator compact stage does not need to measure in the crash zone, where the end dampers are
pressed in. There, the motor must stop anyway. A 230 mm scale reads up to the first touch of each
damper, with 4 mm to spare at each end. The 220 mm scale was 2 mm too short for that. The compact
stage will switch to the 230 mm scale.

## Next Steps

- Ask RSF to confirm that ML 230 mm can be ordered. The catalogue gives a maximum length, but no
  step between lengths.
- Switch the compact stage in aqtuator to MB-MC15-MK-ML230. That is a separate change in the
  aqtuator repository.
- Open the new model in the FreeCAD window once and check that the tape shows and the frames are
  hidden. This was not done in the window here.

- Mass: 0.25 m x 17 g/m = 4.3 g, written as 4 g.
- Built headless with FreeCAD 1.1.3 (`freecadcmd`) on Linux. The current doqs build helper writes
  the view data (`GuiDocument.xml`) after a headless save, so the rule of the 2026-10-20 mistake
  note is met another way. The empty document was created and saved first, then the build script
  ran. The three `IF_` frames were then set hidden, as ADR-005 asks, and the fingerprint was written
  from the saved file.
- The comparison with the RSF 100 mm file was not run again: the private library was not reachable
  here. The check list repeats the results of the 240 mm model and says so.
- The vendor index lists the same two RSF documents for the new part number, with the same
  checksums.
